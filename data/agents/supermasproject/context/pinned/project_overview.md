Partners and members:
- Universite Exemple (coordinator): Marc Leroy (coordinator), Claire Dubois (WP3 leader), Alex Martin (task T3.2 voting-based coordination).
- TU Example (Germany): Jonas Schmidt (WP2 leader, agent models).
- AgentWorks SAS: Nadia Benali (WP4 leader, demonstrator).

Work packages: WP1 coordination, WP2 agent models, WP3 negotiation protocols, WP4 evaluation and demonstrator.
